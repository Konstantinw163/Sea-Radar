# Спецификация задач B-02—B-04

Основано на согласованных значениях и критериях приёмки из `../tasks/SPRINT-01.md`. Результат этих задач: карта пролива Дувр и одно неподвижное демонстрационное судно с карточкой. Движение и остальные демонстрационные суда не входят в этот объём.

## B-02. Карта района

### Решение

- Использовать Leaflet 1.9.x и слой OpenStreetMap Standard по адресу `https://tile.openstreetmap.org/{z}/{x}/{y}.png`.
- Подключать Leaflet только на клиенте; обеспечить подключение его CSS и ненулевую высоту контейнера карты.
- Параметры района и начального вида задать в конфигурации:
  - границы: от 50.75° N, 0.95° E до 51.25° N, 1.95° E;
  - центр: 51.00° N, 1.45° E;
  - zoom: 10.
- Показывать карту на всю доступную область и атрибуцию `© OpenStreetMap contributors`.

### Критерии проверки

- Прямое открытие и обновление страницы отображают карту без ошибки.
- Карту можно двигать и приближать.
- Изменение размера окна корректно перерисовывает карту без артефактов.
- Виден источник карты и атрибуция.
- `next build` завершается успешно.

## B-03. Демонстрационное судно и значок

### Решение

- Использовать согласованную структуру судна:
  - `id`: строка; для единственного судна — `demo-1`;
  - `name`: строка или `null`; пустую строку преобразовывать в `null`;
  - `lat`, `lon`;
  - `speedKnots`: число или `null`;
  - `courseDeg`: число в диапазоне [0, 360) или `null`;
  - `timestamp`: ISO 8601 с часовым поясом;
  - `source`: `'demo'` или `'aisstream'`.
- Задать одно демонстрационное судно внутри границ района с понятным учебным именем. На этом этапе положение неподвижно; маршрут и таймер движения не добавлять.
- Источник данных обозначать подписью «Демонстрационные данные».
- Значок ориентировать по `courseDeg`. При `null` использовать нейтральный круглый значок.
- Добавить значку атрибуты `data-vessel-id="<id>"` и `data-icon="course"|"neutral"`.

### Критерии проверки

- На карте видно одно демонстрационное судно внутри района.
- Подпись «Демонстрационные данные» видна.
- Значок соответствует курсу либо, если курс неизвестен, нейтральный.

## B-04. Выбор судна и карточка

### Решение

- По клику на значок выбирать соответствующее судно и показывать карточку именно этого судна.
- Карточка содержит поля в следующем порядке: идентификатор; название; координаты; скорость; курс; время последнего сообщения; источник.
- Название выводить как текст, не интерпретируя HTML.
- Форматировать значения по согласованным правилам:
  - координаты — `toFixed(5)` с конечными нулями, например `51.00000, 1.45678`;
  - скорость — округление до десятых без конечных нулей и суффикс `уз` (например, `12.3 уз`, `12 уз`, `0 уз`);
  - курс — `Math.round % 360` и `°` (например, `135°`);
  - время — `HH:MM:SS UTC`;
  - неизвестные значения — «Нет данных»; ноль скорости показывать как `0 уз`.
- Источник для демонстрационного судна отображать как «Демонстрационные данные».
- Кнопку закрытия не добавлять. Карточка закрывается только выбором другого судна; повторный клик по выбранному судну и клик по карте не меняют выбор.
- Порядок панели сверху вниз: кнопка (появится позже), подпись источника, карточка. В рамках B-02—B-04 кнопки нет.

### Критерии проверки

- Клик по судну открывает карточку с данными выбранного `id`.
- Повторный клик по этому судну не закрывает карточку.
- Название `<b>Демо</b>`, проверяемое временной правкой конфигурации без коммита, отображается буквальными символами, не как жирный текст.
- Неизвестные значения отображаются как «Нет данных», а нулевая скорость — как `0 уз`.
